# 满分助手 · 海旗版（ycust.haiqikeji.com 适配）

面向 **海旗在线学习平台** 的单文件浏览器用户脚本，当前开源快照版本为 **3.0.2**。脚本提供章节视频自动播放、按目录切换下一节、题干识别与第三方题库检索填答，以及一个可拖动的浮动设置面板。

> **使用前请完整阅读本节。**
>
> - 本项目仅供学习、研究和技术交流，不保证答案正确、学时有效或成绩结果。
> - 脚本包含**自动答题**：会把题干、选项和题型发送给 4 个第三方题库服务，并自动把返回结果填入页面控件。
> - 脚本包含**规避平台播放限制**的行为（强制倍速、拦截进度回拽、删除快进提示、解除复制限制）。
> - 自动化操作可能违反平台规则，并可能影响正常学习记录。请遵守所在学校、课程平台及题库服务的规定，自行承担使用风险。
> - 脚本**没有任何验证码识别或代填逻辑**，验证码必须由本人处理；但它会自动点击部分通用「确定 / 继续 / 知道了」按钮，使用时请留意。
> - 本脚本自述为「由『超星满分助手』移植」的衍生作品，**公开发布前请确认你拥有原作及改编代码的相应授权**，详见[许可证与来源](#许可证与来源)。

## 功能特性

- 自动播放当前页面可见的 `<video>`，支持倍速、自动静音、强制倍速与防回拽。
- 视频播完或检测不到视频时，按课程目录定位当前节并点击下一个**未锁定**的小节。
- 识别单选、多选、判断及部分文本题，向 4 个第三方题库并行检索答案并自动填入。
- 自动提交答卷默认**关闭**；开启后还需「填写率」达到阈值才会尝试点击提交按钮。
- 提供可拖动浮动面板：运行状态、运行日志、公告、题号导航、题库返回详情与设置页。
- 配置与题库令牌保存在脚本管理器存储中；不可用时回退到站点 `localStorage`。
- 单文件分发，无构建步骤、无自动更新、无遥测上报。

**与后续版本的区别：**本仓库是 3.0.2 的独立快照，不含验证码旁观、学时心跳诊断、跨页面日志、单标签页切换锁、控制台 `__mf*` 诊断命令等后来才加入的能力。请不要把其它分支的说明套用到本文件。

## 适用站点与环境

元数据 `@match` 仅覆盖以下范围：

- `*://ycust.haiqikeji.com/*`
- `*://*.haiqikeji.com/*`

也就是说，脚本只在 `haiqikeji.com` 及其子域生效；`ycust.` 前缀那一条与通配规则存在重复。项目名保留「银川科技学院适配」，但实际匹配范围不限于单一学校。

运行环境要求：

| 项目 | 要求 |
| --- | --- |
| 浏览器 | 支持 Shadow DOM、ResizeObserver、MutationObserver、Pointer Events、ES2020 语法的现代 Chrome / Edge / Firefox |
| 脚本管理器 | 支持传统 `GM_*` API 的 Tampermonkey / Violentmonkey |
| 远程依赖 | 首次加载必须能访问 `registry.npmmirror.com` 拉取 Vue 3.3.4、vue-demi 0.14.0、Pinia 2.1.6 |
| 页面结构 | 依赖硬编码的 DOM 选择器；平台改版后可能全部或部分失效 |

`@run-at document-idle` 表示页面空闲阶段启动；`@noframes` 表示脚本**不在 iframe 中运行**，视频或题目若被放进 iframe（尤其是跨域 iframe）将无法识别。

不建议把本文件当作普通 `<script>` 直接注入页面：这样不会自动获得 `@require` 依赖和完整的跨域请求能力。

## 安装

1. 安装用户脚本管理器，例如 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 在 GitHub 仓库中打开 [`ycust_manfen_haiqikeji.user.js`](./ycust_manfen_haiqikeji.user.js)，点击 **Raw**；或在脚本管理器中使用「从 URL 安装」并填入该文件的 Raw 地址。
3. 安装前核对源码中的 `@match`、`@require`、`@connect`、`@grant`。
4. 若脚本管理器提示允许加载远程资源，请确认来源为 `registry.npmmirror.com` 后允许。依赖加载失败时脚本会直接退出，控制台显示「Vue / Pinia 未能加载」。
5. 打开匹配范围内的课程页面并正常登录。页面 `<html>` 上会出现 `data-manfen-initialized` 属性，页面右下出现悬浮球。

> 元数据中没有 `@downloadURL` / `@updateURL`，**本仓库不提供自动更新**。升级需要手动重新安装文件。

## 使用说明

1. 点击悬浮球展开面板，在「设置 / 授权码」中按需填写 `thtoken` / `yztoken` / `ennyctoken`（均**选填**）。
2. 按需调整自动播放、自动切换、自动答题、倍速、静音、提交等选项。设置会自动保存。
3. 进入章节视频页：脚本自动播放并在播完后尝试切换下一节。
4. 进入测验 / 作业 / 考试页：脚本识别题目、请求题库并填答。
5. 题库返回答案后请**人工核对**再决定是否提交；`autoSubmit` 默认关闭。

> **重要：脚本没有总开关。** `autoVideo`、`autoAnswer`、`autoJump`、`autoExam` 默认全部为 `true`，安装后即自动运行。关闭或收起面板**不会**停止主循环（面板关闭只影响界面显示）。如需停用，请在脚本管理器中禁用本脚本，或把上述自动化选项全部关闭。
>
> 面板多处提示「保存后刷新页面生效」，但实际配置在每次主循环和每次题库请求时都会重新读取，部分设置不刷新也会生效。

完整配置项见 [配置项参考](./docs/CONFIG.md)。

## 默认行为

| 行为 | 默认值 | 说明 |
| --- | --- | --- |
| 自动播放 `autoVideo` | 开启 | 只处理顶层文档中第一个可见 `<video>` |
| 自动播放倍速 `playbackRate` | 1 倍 | 强制倍速 `forceRate` 默认开启，会覆盖平台写回的倍速值 |
| 自动静音 `muted` | 开启 | 只置静音，不会主动取消静音 |
| 防回拽 `antiRewind` | 开启 | 仅在倍速大于约 1.05 时真正生效；会改写页面 `HTMLMediaElement.prototype.currentTime` |
| 自动切换 `autoJump` | 开启 | 视频播完或「无视频」时复用此开关；章节切换有 8 秒冷却 |
| 主循环间隔 `interval` | 3 秒 | 每轮检测间隔 |
| 每题间隔 `answerInterval` | 3 秒 | 答题流程中每道题之间的等待 |
| 自动答题 `autoAnswer` | 开启 | 识别到题目后会并行请求第三方题库 |
| 考试自动切题 `autoExam` | 开启 | 关闭时非考试页仍可能点击「下一题 / 继续」等按钮 |
| 自动提交 `autoSubmit` | **关闭** | 开启后还需填写率 ≥ `minAccuracy` 才尝试点击提交 |
| 最低匹配率 `minAccuracy` | 0.8 | 实际是「成功填写题数 ÷ 识别题数」，**不是答案正确率** |
| 普通弹窗处理 | 始终开启 | 自动点击「确定 / 继续 / 知道了 / 关闭」等按钮，无独立开关 |
| 解除复制限制 | 始终开启 | 清空页面复制/剪切/粘贴/选择/拖拽处理并注入 `user-select:auto`，无独立开关 |
| 验证码 | 无相关逻辑 | 不识别、不代填、不等待；需要本人处理 |
| 运行日志 | 内存 20 条 | 刷新即清空，无持久化、无导出命令 |

## 第三方题库与网络请求

脚本在识别到题目后，会通过 `GM_xmlhttpRequest` **并行**向以下 4 个服务发起请求：

| 服务 | 端点 | 协议 | 发送内容 | 触发条件 |
| --- | --- | --- | --- | --- |
| 题库海 | `https://api.tikuhai.com/search` | HTTPS | 题干、选项、题型、`key`（`thtoken`）、`v` 版本头 | **无条件**，未填 token 时 `key` 为空串仍会请求 |
| 一之题库 | `http://cx.icodef.com/wyn-nb?v=4` | **明文 HTTP** | 题干、`Authorization` 头（`yztoken`） | 填写 `yztoken` 后 |
| 言溪题库 | `https://tk.enncy.cn/query` | HTTPS | 题干、`token`（`ennyctoken`） | 填写 `ennyctoken` 后 |
| 木可题库 | `https://api.muketool.com/cx/v2/query` | HTTPS | 题干、题型 | **无条件**，无需任何 token |

请特别注意：

- **不填任何令牌，也会有两个服务收到题目内容。**「数据只在本地处理」的说法不成立。
- 题干文本最多会被外发 4 次；选项文本只发给 `api.tikuhai.com`。脚本**不发送** Cookie、账号密码、成绩或页面整体 DOM；唯一的请求点就是题库检索。
- 一之题库使用**明文 HTTP**，`yztoken` 和题干在传输中可能被窃听或篡改，也可能被浏览器按混合内容拦截。源码注释声称「全部 https」，与此处实现不符。请勿复用其他服务的高价值令牌。
- 题库响应只用于填答和面板展示，脚本不保证答案正确，也不验证服务端结果。公告中亦声明「不对题库准确率以及可用性负责」。
- 题库返回内容通过 `innerHTML` 渲染到面板（见 [安全政策](./SECURITY.md)），第三方响应不受本仓库控制。
- 若脚本管理器不提供 `GM_xmlhttpRequest`，会降级为受 CORS / 混合内容限制的 `fetch`，此时题库通常拿不到答案。

本脚本**不会**向平台域名伪造学时、心跳或播放接口请求，也不会修改 `document.title`。学时推进完全依赖 DOM 播放与点击章节项。

## 权限说明

| 元数据 / 权限 | 实际用途 |
| --- | --- |
| `@match` × 2 | 限定在 `haiqikeji.com` 及其子域运行 |
| `@require` × 3 | 加载 Vue 3.3.4、vue-demi 0.14.0、Pinia 2.1.6（来自 `registry.npmmirror.com`，运行时远程代码） |
| `@connect` × 4 | 允许向上述 4 个题库域名发起跨域请求 |
| `GM_getValue` / `GM_setValue` | 保存 `config`（含 3 个令牌）和面板位置 `manfen:panel-position` |
| `GM_xmlhttpRequest` | 唯一的跨域请求通道；缺失时降级 `fetch` |
| `unsafeWindow` | 访问页面 realm 的 DOM 原型、事件构造、`localStorage` 和 `ResizeObserver`，并改写 `HTMLMediaElement.prototype.currentTime` |
| `GM_info` | 定义了兜底变量但代码中**未被使用**，无实际效果 |
| `@run-at document-idle` | 页面空闲阶段启动 |
| `@noframes` | 不在 iframe 内启动 |

未申请 `GM_addStyle`、`GM_registerMenuCommand`、`GM_notification`、`GM_download`、`GM_openInTab` 等权限；样式通过注入 `<style>` 元素实现。

## 隐私与本地数据

- 配置（含令牌）与面板位置优先存于脚本管理器存储；`GM_*` 不可用时回退到页面 `localStorage`，键名前缀为 `manfen:`（面板位置实际会写成 `manfen:manfen:panel-position`）。
- 令牌输入框是 `type="password"`，**只是视觉遮挡，本地存储并未加密**。不要在共享浏览器配置中保存敏感令牌。
- 脚本不读写 `document.cookie`，不调用页面自身的业务 JS，不向 `window` 暴露全局函数或调试接口。
- 运行日志是内存数组，最多保留最近 20 条，不写入磁盘、不上传，刷新页面即清空；日志内容主要是状态文案和章节/题目片段。
- 对外提交 Issue 或分享截图前，请删除题库令牌、Cookie、个人课程信息和敏感 URL 参数。

## 排查与常见问题

本版本**没有** `__mfDiag()` 之类的控制台诊断命令。排查只能依赖浏览器 DevTools、面板「运行日志」tab 和源码断点。

### 面板完全不出现

检查 URL 是否匹配、脚本是否启用、三个 `@require` 依赖是否加载成功，以及控制台是否出现「Vue / Pinia 未能加载」。

### 视频不自动播放

浏览器可能拦截自动播放（脚本只提示「请先点击页面任意位置」，不会重试或跳过）。也可能是 `<video>` 选择器不匹配，或视频位于 iframe 内（`@noframes` 无法处理）。

### 一直提示「未检测到视频，尝试切换章节」

章节目录的 `.section-item` / `.active` 结构可能已变化，或当前节尚未渲染；脚本在无法定位当前节时只等待，不会回退点第一节。切换还有 8 秒冷却。

### 提示「后续章节处于锁定状态，暂不切换」

命中 `.locked` 或 `.lock-icon` / `.unlock-time` 的章节会被跳过，脚本不会强行解锁。

### 识别不到题目 / 有答案没填上

`SITE.question` 与 radio/checkbox 分组兜底都依赖现有 DOM。选择/判断题走选项匹配，文本题才写文本框；答案为空、含「付费题库 / 暂无答案」或被阻断词过滤时不会填写。一之、言溪在未配置对应 token 时会直接跳过请求。

### 刷新后日志没了

设计如此：日志只存内存，最多 20 条。

### 版本号对不上

元数据 `@version` 是 `3.0.2`、面板显示 `v3.0.2`，但内部 `SCRIPT_VERSION` 仍是 `3.0.0`，发给题库的版本头 `v` 也是 `3.0.0`。这是已知不一致，**以元数据 `@version 3.0.2` 为准**。

## 已知限制与已知问题

- **无总开关**：安装即自动运行；关闭面板不会停止主循环。
- **无验证码逻辑**：不会识别、代填或等待验证码；但 `closeDialogs()` 会自动点击通用「确定 / 继续 / 知道了」按钮，正则匹配较宽，存在误触风险。
- **绕过平台限制**：强制倍速会劫持实例 `playbackRate` setter；防回拽会改写页面媒体原型且安装后不还原；还会删除「不允许快进 / 请勿快进」提示并解除复制限制。这些行为可能影响正常拖动进度或平台记录。
- **自动提交风险**：开启后只尝试点击提交按钮，不验证服务端结果；`minAccuracy` 在设置界面没有数值校验，输入非数字可能绕过阈值判断。
- **注入面**：题库返回文本以 `innerHTML` 渲染进 Shadow DOM，未转义。详见 [SECURITY.md](./SECURITY.md)。
- **强依赖站点结构**：所有视频、章节、题目、按钮选择器均为硬编码；无 `@updateURL`，改版需人工修复并重新发布。
- **无 iframe 支持**：`@noframes`，且所有查找只扫描顶层 `document`。
- **版本漂移与死代码**：`@version 3.0.2` / `SCRIPT_VERSION 3.0.0` 不一致；`debugger`、`notice`、`questionType`、`removeHtml`、`cl`、`_GM_info` 定义后未使用；`debugger` 开关读取的是默认值，实际无法启用。
- **注释与实现不符**：源码声称题库「全部 https」，但一之题库仍是明文 HTTP。
- **图片题干、复杂富文本、非标准题型**可能无法解析；题库答案准确性不受保证。
